

## 阶段二：服务器拉取代码并重启

**在哪执行**：SSH 登录服务器后的 bash。

**第 1 步，确认服务器代码来源**：

```bash
cd /root/xuanshiai && git remote -v
```

看 `origin` 是不是你刚 push 的那个地址。若对不上，跳到本阶段末尾的「scp 备选」。

**第 2 步，拉取**：

```bash
cd /root/xuanshiai && git pull --ff-only origin main
```

**预期**：出现本次 8 个文件的更新，结尾 `Fast-forward`。

> 若报 `local changes would be overwritten`：先 `git stash`（暂存本地改动）再 `git pull --ff-only origin main`，然后 `git stash pop`。别用 `git reset --hard`。

**第 3 步，找服务名并重启**：

```bash
systemctl list-units --type=service | grep -iE "xuan|uvicorn|gunicorn|fastapi|api"
```

**预期**：出现形如 `xuanshiai.service` 的一行。用真实服务名替换下面命令里的 `<服务名>`：

```bash
systemctl restart <服务名>
systemctl status <服务名> --no-pager
```

**预期**：`Active: active (running)`。

> 如果你的服务不是 systemd 管的（比如 `nohup`、`supervisor`、`pm2`、`uvicorn --reload` 手工起），就用你平时重启它的方式。重启是必须的——`Settings` 是启动期加载，不重启新代码和新配置都不生效。

**scp 备选（服务器拉不动 GitHub 时）**：在本机 PowerShell 把 6 个代码文件直接传上去（`docs` 不用传），再在服务器重启：

```powershell
scp app/core/redis.py app/services/discovery.py app/services/quotas.py app/api/routes/ai_moxiang.py tests/test_discovery_features.py root@<服务器IP>:/root/xuanshiai/app/../app/
```

（`tests` 可不传，不影响运行；`scripts/seed_plain_test_account.py` 单独传一次给阶段三用。）

## 阶段四：服务器额度快照设为 8

**在哪执行**：服务器 bash。

**第 1 步，先看这行在不在**：

```bash
mysql -uroot -p xuanshiai -e "SELECT id,namespace,version,JSON_KEYS(config_json) k,updated_at FROM admin_config_snapshot WHERE namespace='platform_permissions';"
```

**分支 A：有输出（行已存在）** —— 只改一个键，不动其它键：

```bash
mysql -uroot -p xuanshiai -e "UPDATE admin_config_snapshot SET config_json=JSON_SET(config_json,'\$.free_browse_daily_limit',8), version=version+1, updated_at=UTC_TIMESTAMP() WHERE namespace='platform_permissions';"
```

> 注意反斜杠 `\$`：bash 双引号里 `$` 会被当变量展开，所以 SQL 里的 `$.free_browse_daily_limit` 要写成 `\$.free_browse_daily_limit` 转义，否则 `$` 后面会被吃掉。

**分支 B：无输出（行不存在）** —— 插入完整默认（不要只插一个键）：

```bash
mysql -uroot -p xuanshiai -e "INSERT INTO admin_config_snapshot (namespace,name,description,version,config_json,sensitive_keys_json) VALUES ('platform_permissions','平台权限配置','浏览、资料查看、牵线和会员状态权限',1,JSON_OBJECT('default_show_gender','opposite','incomplete_browse_pages',2,'free_browse_daily_limit',8,'high_match_browse_bonus',5,'free_apply_daily_limit',3,'vip_apply_daily_limit',10,'free_superlike_daily_limit',1,'vip_superlike_daily_limit',3,'paper_plane_daily_limit',3,'incomplete_profile_access',false,'show_matched_members',true,'non_vip_photo_limit',1,'non_vip_video_limit',0),'[]') ON DUPLICATE KEY UPDATE config_json=JSON_SET(config_json,'\$.free_browse_daily_limit',8), version=version+1, updated_at=UTC_TIMESTAMP();"
```

**第 2 步，回读确认**：

```bash
mysql -uroot -p xuanshiai -e "SELECT JSON_EXTRACT(config_json,'\$.free_browse_daily_limit') FROM admin_config_snapshot WHERE namespace='platform_permissions';"
```

**预期**：输出 `8`。

## 阶段五：`.env` 双保险 + AI 开关（需你拍板）

**在哪执行**：服务器 bash。

**第 1 步，看现状**（只读，不改）：

```bash
cd /root/xuanshiai && grep -E "ENVIRONMENT|BROWSE_DAILY_LIMIT|AI_MASTER_ENABLED|AI_PROFILE_ENABLED|AI_MOXIANG_JOURNEY_ENABLED|AI_PROVIDER" .env
```

把这 6 行的输出**贴回给我**（AI 相关的 key 值不用贴，我只要"有/无 + 是否 true"）。

**第 2 步，额度双保险（推荐）**：把 `BROWSE_DAILY_LIMIT=20` 改成 `8`：

```bash
cd /root/xuanshiai && sed -i 's/^BROWSE_DAILY_LIMIT=.*/BROWSE_DAILY_LIMIT=8/' .env && grep BROWSE_DAILY_LIMIT .env
```

> 不改也不会立即出错（快照优先），改了能防"快照行被删后额度静默跳回 20"。

**第 3 步，AI 开关二选一**：

- **要验 AI 画像** → 追加三行（若已有就改成 true）：

```bash
cd /root/xuanshiai
grep -q "^AI_MOXIANG_JOURNEY_ENABLED=" .env || echo "AI_MOXIANG_JOURNEY_ENABLED=true" >> .env
sed -i 's/^AI_MOXIANG_JOURNEY_ENABLED=.*/AI_MOXIANG_JOURNEY_ENABLED=true/' .env
grep -q "^AI_MASTER_ENABLED=" .env || echo "AI_MASTER_ENABLED=true" >> .env
sed -i 's/^AI_MASTER_ENABLED=.*/AI_MASTER_ENABLED=true/' .env
grep -q "^AI_PROFILE_ENABLED=" .env || echo "AI_PROFILE_ENABLED=true" >> .env
sed -i 's/^AI_PROFILE_ENABLED=.*/AI_PROFILE_ENABLED=true/' .env
grep -E "AI_MOXIANG_JOURNEY_ENABLED|AI_MASTER_ENABLED|AI_PROFILE_ENABLED" .env
```

- **本轮不验 AI 画像** → 什么都不改，但要记得告知测试方"画像/墨相 503 属功能未开放"。

**第 4 步（改了 .env 就必须做）重启**：

```bash
systemctl restart <服务名>
```

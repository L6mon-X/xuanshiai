# 扣减积分接口（A12-积分）

> 变更日期：2026-10-24　关联清单：`后端接口缺失清单.md` 第 391 行「扣减积分：`credit-grants` 只能发放不能扣减」
> 口径：**与「发放积分」`credit-grants` 对称**，写 `account_ledger` DEBIT，**不新建表、不直改 C 端 `user_points`**。

## 0. 积分口径说明（重要）

- 设计文档《会员体系和积分体系设计》明确：C 端积分账本是 `user_points`，且「积分不支持前端直接修改」。
- 后台「积分明细」页与「发放积分」`credit-grants` 实际读写的是 **`account_ledger`（`account_type='user'`、`source_type='admin_grant'`）**，是与 C 端 `user_points` 并存的另一套后台额度概念。
- 本接口与 `credit-grants` **同账本同 `source_type`**，保证发放/扣减在同一「积分明细」页可见、成对可核对。
- 会员列表 `points` 展示/排序仍按设计文档口径取 `user_points`（见 `docs/api/会员CRM列表接口.md`），与本后台积分相互独立。

## 1. 扣减积分

**`POST /api/v1/admin/finance/credit-deductions`**

| 项 | 说明 |
|---|---|
| 权限 | `finance.write` |
| Content-Type | `application/json` |
| 状态码 | 成功 `201` |
| **敏感操作** | Header `Idempotency-Key`（8–128）且 Query `confirm=true`；**缺 `confirm` → `428`；缺/非法幂等键 → `422`。** |
| 原子性 | 扣减前对本批账户 `FOR UPDATE` 加行锁并校验可用额度，**任一不足整批 `409`，不产生部分扣减** |

### 请求

Query：`confirm=true`（必填）
Header：`Idempotency-Key: <8-128 chars>`（必填）

Body `CreditDeductRequest`（字段与 `CreditGrantRequest` 对称）：

| 字段 | 类型 | 必填 | 约束 | 说明 |
|---|---|---|---|---|
| `target_type` | string | 是 | `all` \| `member` \| `verified` \| `matchmaker_team` | 扣减目标范围 |
| `user_ids` | array[int] | 条件 | `target_type=member` 必填，≤5000 | 指定会员 ID |
| `amount` | int | 是 | `>0`、`≤1000000` | **每人**扣减积分数 |
| `reason` | string | 是 | 1–20 字 | 扣减理由，记入审计 |

```http
POST /api/v1/admin/finance/credit-deductions?confirm=true
Idempotency-Key: credit-deduct-20261024-0001
Content-Type: application/json

{ "target_type": "member", "user_ids": [10086], "amount": 50, "reason": "违规扣除" }
```

### 响应 `CreditDeductResult`

| 字段 | 类型 | 说明 |
|---|---|---|
| `deducted_count` | int | 实际扣减账户数（去重） |
| `total_amount` | int | `deducted_count * amount` |
| `sample_ledger_ids` | array[int] | 前 10 条 `account_ledger.id` 样本 |
| `target_user_ids` | array[int] | 命中 user_id 列表 |

### 错误码

| 状态码 | 场景 |
|---|---|
| `404` | 扣减目标为空 / `target_type` 非法 |
| `409` | 存在可用积分不足的用户，整批未执行（detail 附前 20 个 ID） |
| `428` | 缺 `confirm=true` |
| `422` | 缺/非法 `Idempotency-Key`，或参数越界 |

# 后台账号修改密码

#### `POST /api/v1/admin/matchmaker/auth/change-password`

**基本信息**：修改当前已登录的红娘后台账号密码。需要 Bearer 登录令牌和当前账号会话；请求与响应均为 JSON，成功状态码为 `204 No Content`。

**请求参数**：

| 参数 | 位置 | 类型 | 必填 | 校验 | 含义 |
| --- | --- | --- | --- | --- | --- |
| `old_password` | body | string | 是 | 1-128 字符 | 当前密码 |
| `new_password` | body | string | 是 | 8-128 字符，不能与旧密码相同 | 新密码 |

请求示例：

```http
POST /api/v1/admin/matchmaker/auth/change-password
Authorization: Bearer <access-token>
Content-Type: application/json
```

```json
{"old_password":"old-password","new_password":"new-password-123"}
```

**返回**：无返回体。

**业务规则**：仅允许修改当前登录账号；密码使用 bcrypt 哈希保存，不回传明文或哈希；成功后当前会话保持有效，后续登录必须使用新密码。

**错误**：

| 状态码 | 触发条件 | 响应示例 |
| --- | --- | --- |
| `400` | 旧密码错误或新旧密码相同 | `{"detail":"旧密码不正确"}` |
| `401` | 令牌无效或已过期 | `{"detail":"未登录"}` |
| `422` | 新密码少于 8 位或字段缺失 | FastAPI 参数校验错误 |

**兼容性**：新增接口，不改变已有登录、重置密码接口。

## `POST /api/v1/support/feedback`

**基本信息**

- 用途：提交意见 / BUG / 建议 / 投诉
- URL：`/api/v1/support/feedback`
- Method：`POST`
- 是否需要登录：是
- 所需角色/权限：任意登录用户
- Content-Type：`application/json`
- 成功状态码：`201 Created`

**请求参数**

| 参数 | 位置 | 类型 | 必填 | 默认 | 校验 | 含义 |
|---|---|---|---|---|---|---|
| `Idempotency-Key` | header | string | 是 | — | 8–128 字符 | 幂等键；同键同载荷只创建一条 |
| `category` | body | string | 否 | `咨询` | `咨询` / `BUG` / `建议` / `投诉` | 反馈分类 |
| `content` | body | string | 是 | — | 1–2000 字符，去空白后不能为空 | 反馈内容 |
| `images` | body | string[] | 否 | `[]` | 最多 9 个，每项 1–500 字符 | 截图 URL |
| `contact_phone` | body | string | 否 | `null` | `^1[3-9]\d{9}$` | 联系手机号 |

**请求示例**

```http
POST /api/v1/support/feedback
Authorization: Bearer <access_token>
Idempotency-Key: feedback-20261102-0001
Content-Type: application/json
```

```json
{
  "category": "建议",
  "content": "希望增加夜间模式",
  "images": ["https://cdn.example.com/feedback/a.webp"],
  "contact_phone": "13900000002"
}
```

非法示例（内容为空 → 422）：

```json
{ "category": "建议", "content": "   " }
```

**返回参数**

| 字段 | 类型 | 必返 | 含义 |
|---|---|---|---|
| `id` | integer | 是 | 反馈 ID |
| `category` | string | 是 | 分类 |
| `content` | string | 是 | 内容 |
| `images` | string[] | 是 | 截图 URL，空为 `[]` |
| `contact_phone` | string \| null | 是 | 联系手机号 |
| `status` | integer | 是 | `0` 待处理 / `1` 处理中 / `2` 已回复 / `3` 已关闭 |
| `reply_content` | string \| null | 是 | 客服回复 |
| `replied_at` | string \| null | 是 | 回复时间（ISO 8601） |
| `created_at` | string \| null | 是 | 创建时间 |

**返回示例**

```json
{
  "id": 5,
  "category": "建议",
  "content": "希望增加夜间模式",
  "images": ["https://cdn.example.com/feedback/a.webp"],
  "contact_phone": "13900000002",
  "status": 0,
  "reply_content": null,
  "replied_at": null,
  "created_at": "2026-11-02T10:00:00"
}
```

**错误**

| HTTP | 触发条件 | 响应示例 | 前端处理 |
|---|---|---|---|
| 401 | 未登录 / token 失效 | `{"detail":"请先登录"}` | 跳登录 |
| 409 | 同键不同载荷，或同键请求处理中 | `{"detail":"Idempotency-Key 已用于不同请求"}` | 换新键重试 |
| 422 | 内容为空、超长、图片/手机号格式非法 | pydantic 校验数组 | 按字段提示 |
| 429 | 当日已提交 10 条 | `{"detail":"今日反馈次数已达上限（10 条）"}` | 提示明日再试 |
| 503 | Redis 不可用（生产 fail-closed） | `{"detail":"Redis服务未配置或暂时不可用"}` | 稍后重试 |

**使用方法与业务规则**

1. 前置条件：登录。
2. 幂等：必须携带 `Idempotency-Key`；同键同载荷重复提交返回首次结果，不重复入库。
3. 额度：每用户每日最多 10 条，按 UTC 自然日重置。
4. 并发：幂等预占在写库前完成，重复请求不会创建两条。

## `GET /api/v1/support/feedback/mine`

**基本信息**

- 用途：查看本人提交的反馈与回复
- URL：`/api/v1/support/feedback/mine?page=1&page_size=20`
- Method：`GET`
- 是否需要登录：是
- 成功状态码：`200 OK`

**请求参数**

| 参数 | 位置 | 类型 | 必填 | 默认 | 校验 | 含义 |
|---|---|---|---|---|---|---|
| `page` | query | integer | 否 | `1` | 1–10000 | 页码 |
| `page_size` | query | integer | 否 | `20` | 1–100 | 每页条数 |

**返回参数**

| 字段 | 类型 | 必返 | 含义 |
|---|---|---|---|
| `items` | array | 是 | 反馈列表，字段同创建接口返回 |
| `page` | integer | 是 | 当前页 |
| `page_size` | integer | 是 | 每页条数 |
| `total` | integer | 是 | 总条数 |
| `has_more` | boolean | 是 | 是否还有下一页 |

无数据示例：

```json
{ "items": [], "page": 1, "page_size": 20, "total": 0, "has_more": false }
```

**业务规则**：只返回 `user_id = 当前用户` 的记录，越权查询他人返回空列表而非 403。

## `GET /api/v1/support/help-docs`

**基本信息**

- 用途：读取后台「使用帮助文档」内容
- URL：`/api/v1/support/help-docs?page=1&page_size=20&keyword=认证`
- Method：`GET`
- 是否需要登录：否
- 成功状态码：`200 OK`

**请求参数**

| 参数 | 位置 | 类型 | 必填 | 默认 | 校验 | 含义 |
|---|---|---|---|---|---|---|
| `page` | query | integer | 否 | `1` | 1–10000 | 页码 |
| `page_size` | query | integer | 否 | `20` | 1–100 | 每页条数 |
| `keyword` | query | string | 否 | — | ≤64 字符 | 标题/副标题/正文模糊匹配 |

**返回参数**

| 字段 | 类型 | 必返 | 含义 |
|---|---|---|---|
| `items[].id` | integer | 是 | 文档 ID |
| `items[].title` | string | 是 | 标题 |
| `items[].subtitle` | string \| null | 是 | 副标题 |
| `items[].category` | string \| null | 是 | 分类（取自 `extra_json.category`） |
| `items[].body` | string \| null | 是 | 正文（取自 `extra_json.body`） |
| `items[].updated_at` | string \| null | 是 | 更新时间 |
| `page` / `page_size` / `total` / `has_more` | — | 是 | 分页字段 |

**业务规则**：只返回 `domain='help_doc'` 且 `status=1` 的文档；内容由管理端
`/admin/help-docs` 维护，C 端只读。

## `POST /api/v1/admin/user-feedback/{feedback_id}/reply`

**基本信息**

- 用途：回复用户反馈，状态置为「已回复」
- URL：`/api/v1/admin/user-feedback/{feedback_id}/reply?confirm=true`
- Method：`POST`
- 权限：`matchmaker.system.manage`
- 成功状态码：`200 OK`

**请求参数**

| 参数 | 位置 | 类型 | 必填 | 默认 | 校验 | 含义 |
|---|---|---|---|---|---|---|
| `feedback_id` | path | integer | 是 | — | ≥1 | 反馈 ID |
| `Idempotency-Key` | header | string | 是 | — | 8–128 字符 | 幂等键 |
| `confirm` | query | boolean | 是 | `false` | 必须为 `true` | 敏感操作二次确认 |
| `reply_content` | body | string | 是 | — | 1–2000 字符 | 回复内容 |

**返回**：更新后的 `AdminFeedbackItem`（`status=2`、`replied_by`、`replied_at`）。

**错误**

| HTTP | 触发条件 | 前端/后台处理 |
|---|---|---|
| 401/403 | 未登录或无权限 | 重新登录 / 申请权限 |
| 404 | 反馈不存在 | 刷新列表 |
| 422 | 回复为空或超长 | 按字段提示 |
| 428 | 缺少 `confirm=true` | 补二次确认 |
| 409 | 幂等键冲突 | 换新键重试 |

**业务规则**：回复写入 `user_feedback.reply_content`、`replied_by`、`replied_at`，
状态置 `2`，并写 `business_audit_log(action='support.feedback.reply')`。

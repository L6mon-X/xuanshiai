# 一键刷新 IP / 手机属地接口（A12-属地）

> 变更日期：2026-10-24　关联清单：`后端接口缺失清单.md` 第 406–407 行「一键更新 IP/手机属地」
> 口径：**provider 门控骨架（fail-closed）**。本仓库无 IP→属地、号码归属地解析器（外部厂商依赖），
> 本次把「死按钮」变成**可调用、可探测、语义诚实**的接口，**不伪造真实地理值**、**不新建表**。

## 0. 重要说明（务必如实告知前端/产品）

- **`users.ip_region` / `users.phone_region` 展示列已存在**（迁移已补），列表/详情返回。
- **真实属地刷新尚未接入**：需要外部 IP 库 / 号码归属地服务。当前 `region_resolver_provider` 缺省 `"disabled"`，
  调用刷新接口一律返回 `503`，**不会写库、不会造假数据**。
- 接入路径：在 `app/core/config.py` 配置 `REGION_RESOLVER_PROVIDER=real` 并实现适配器（`adapter_implemented` 置 `true`），
  本接口即可切换为真实刷新。**未实现适配器前，`real` 返回 `501`。**

## 1. Provider 门控矩阵

`settings.region_resolver_provider`（`Literal["disabled","mock","real"]`，缺省 `disabled`）：

| provider | `POST refresh-*` 行为 | 状态码 | 是否写库 |
|---|---|---|---|
| `disabled`（缺省） | 拒绝：厂商未配置 | `503` | 否 |
| `mock` | 干跑（dry-run）：仅统计候选行数，`updated_count=0` | `200` | **否** |
| `real` | 适配器待接入 | `501` | 否 |

> 生产/预发环境（`environment in {staging, production}`）禁止 `mock`：`config.py` 校验器直接 `raise ValueError`，服务启动即失败。

## 2. 查询属地解析服务状态

**`GET /api/v1/admin/matchmaker/members/region-resolver`**

| 项 | 说明 |
|---|---|
| 权限 | `matchmaker.member.read` |
| 用途 | 只读目录，供前端判断按钮是否可用（不受写开关影响） |

### 响应 `RegionResolverStatus`

| 字段 | 类型 | 说明 |
|---|---|---|
| `provider` | string | `disabled` / `mock` / `real` |
| `refresh_enabled` | bool | `provider != "disabled"` 时为 `true` |
| `adapter_implemented` | bool | 适配器是否已实现（当前恒为 `false`） |

## 3. 一键刷新 IP 属地

**`POST /api/v1/admin/matchmaker/members/refresh-ip-region`**

| 项 | 说明 |
|---|---|
| 权限 | `matchmaker.member.manage` |
| **敏感操作** | Header `Idempotency-Key`（8–128）且 Query `confirm=true`；缺 `confirm` → `428`，缺/非法键 → `422` |
| 幂等 | `mock` 下走 begin/replay，同键返回上次结果 |

## 4. 一键刷新手机属地

**`POST /api/v1/admin/matchmaker/members/refresh-phone-region`**

约束与状态码同上；差异仅在数据源列：IP 用 `users.register_ip`，手机属地用 `users.phone`。

```http
POST /api/v1/admin/matchmaker/members/refresh-ip-region?confirm=true
Idempotency-Key: refresh-ip-20261024-0001
```

### 响应 `RegionRefreshResult`（仅 `mock` 干跑返回体）

| 字段 | 类型 | 说明 |
|---|---|---|
| `kind` | string | `ip` / `phone` |
| `provider` | string | 当前 provider |
| `dry_run` | bool | `mock` 下恒 `true`（未真正写库） |
| `scanned_count` | int | 作用域内、源列非空的候选行数 |
| `updated_count` | int | 干跑恒 `0`（未写入） |
| `adapter_implemented` | bool | 恒 `false` |

```json
{ "kind": "ip", "provider": "mock", "dry_run": true, "scanned_count": 1234, "updated_count": 0, "adapter_implemented": false }
```

### 错误码

| 状态码 | 场景 |
|---|---|
| `428` | 缺 `confirm=true` |
| `422` | 缺/非法 `Idempotency-Key` |
| `503` | provider=`disabled`（未接入厂商） |
| `501` | provider=`real`（适配器待实现） |

## 5. 作用域与降级

- 候选统计走 D-16 数据作用域 `scope_assignment.user_id = users.id`；
- `users.deleted_at` 列存在时追加 `AND users.deleted_at IS NULL`（不排除软删行）；
- 源列（`register_ip` / `phone`）存在时追加非空过滤，缺列则不拼，避免 Unknown column。

# CMS 更新公告与使用帮助文档接口（A11-CMS）

> 变更日期：2026-10-24　关联清单：`后端接口缺失清单.md` A11「系统更新公告 / 使用帮助文档」
> 口径：**轻量 CRUD（标题 + 正文 + 分类），复用通用内容表 `admin_content_item`，不新建表**（PROJECT_RULES §2.4）。
> 前端约定路径为 `/admin/update-reports`、`/admin/help-docs`；本模块只在其上包一层薄路由，读写与校验全部委托 `admin_content` 服务。

## 1. 数据模型（复用，不新建表）

内容落通用表 `admin_content_item`，用 `domain` 区分两类：

| domain | 含义 | 路径前缀 |
|---|---|---|
| `update_report` | 系统更新公告 | `/api/v1/admin/update-reports` |
| `help_doc` | 使用帮助文档 | `/api/v1/admin/help-docs` |

字段映射：

| 概念 | 落库位置 |
|---|---|
| 标题 | `title` |
| 副标题/摘要 | `subtitle` |
| 封面图 | `image_url` |
| 状态 | `status`（`1` 正常 / `2` 停用） |
| 排序 | `sort` |
| **正文（富文本/Markdown）** | `extra_json.body` |
| **分类** | `extra_json.category` |

权限沿用通用内容域口径：读 `platform.config.read`，写 `platform.config.write`。

## 2. 端点一览

两类资源同构，各 5 个端点（`update-reports` 与 `help-docs` 路径互换即可）：

| 方法 & 路径 | 权限 | 状态码 | 说明 |
|---|---|---|---|
| `GET /api/v1/admin/update-reports` | config.read | 200 | 列表（分页） |
| `GET /api/v1/admin/update-reports/{item_id}` | config.read | 200 | 详情 |
| `POST /api/v1/admin/update-reports` | config.write | 201 | 新增 |
| `PATCH /api/v1/admin/update-reports/{item_id}` | config.write | 200 | 更新 |
| `DELETE /api/v1/admin/update-reports/{item_id}` | config.write | 204 | 删除 |

`help-docs` 五个端点同上，仅路径替换为 `/api/v1/admin/help-docs`。

### 列表查询参数（`GET`）

| 参数 | 类型 | 默认 | 约束 | 说明 |
|---|---|---|---|---|
| `page` | int | 1 | 1–10000 | 页码 |
| `page_size` | int | 20 | 1–100 | 每页数量 |
| `keyword` | string? | – | ≤64 | 标题/正文模糊 |
| `status` | int? | – | 1–2 | 状态过滤 |
| `category` | string? | – | ≤32 | **仅 update-reports**：按 `extra.category` 分类筛选 |

> 说明：`category` 过滤挂在 update-reports；help-docs 列表当前不接 `category`（保持轻量），需要时按同一 `EXTRA_FILTER_KEYS` 机制扩展。

### 请求体

`POST` → `ContentItemCreate`：`title`（≤255）、`subtitle?`（≤500）、`image_url?`（≤500）、`amount?`、`status`（默认 1）、`sort`（默认 0）、`extra`（dict，正文放 `extra.body`、分类放 `extra.category`）。

`PATCH` → `ContentItemUpdate`：以上字段均可选（含 `extra`），只更新传入项。

```http
POST /api/v1/admin/update-reports
Authorization: Bearer <admin-access-token>
Content-Type: application/json

{"title":"v2.3 更新公告","status":1,"sort":0,"extra":{"category":"功能","body":"<p>新增模拟登录只读会话</p>"}}
```

### 响应

- 详情/新增/更新返回 `ContentItem`：`{id, domain, title, subtitle, image_url, amount, status, sort, extra, created_at, updated_at}`。
- 列表返回 `ContentItemPage`：`{total, page, page_size, items[]}`。

## 3. 域登记与委托（实现要点）

- `app/services/admin_content.py`：`ALLOWED_DOMAINS` 增 `update_report` / `help_doc`；`EXTRA_FILTER_KEYS` 支持 `category`；提供 `get_item` 详情读取。
- `app/api/routes/admin_cms.py`：`update_report_router`（prefix `/admin/update-reports`）与 `help_doc_router`（prefix `/admin/help-docs`），全部委托 `list_items/create_item/update_item/delete_item/get_item`；`@declare_permission` + `current.require(...)` 声明并校验 `platform.config.{read,write}`。
- `app/api/router.py`：注册两个子路由（tags=管理后台）。

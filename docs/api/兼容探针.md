# 兼容探针接口

为兼容 OpenAI 客户端和部署探针，服务提供只读、无需登录的模型/状态发现接口。响应只包含公开服务元数据，不返回 API Key、数据库连接串或其他密钥。

## `GET /api/v1/models`（兼容别名 `/api/models`）

无请求体。返回当前配置的主 AI 模型；若配置了 AI 分身模型则一并列出。

```json
{
  "object": "list",
  "data": [
    {"id": "deepseek-chat", "object": "model", "created": 1790000000, "owned_by": "mock"}
  ]
}
```

`created` 为当前服务生成时间戳，不表示模型发布时间。未知路径仍返回 404；本接口不承诺提供聊天生成能力。

## `GET /api/v1/status`（兼容别名 `/api/status`）

无请求体，返回 `status`、`service`、`version`、`environment` 和 `api_prefix`。仅表示进程已响应，不代表数据库、Redis 或第三方 AI 服务可用；需要依赖检查时使用 `GET /api/v1/health` 及业务探针。

## `GET /api/v1/config`（兼容别名 `/api/config`）

无请求体，返回脱敏公开配置：服务版本、API 前缀、AI provider 名称、模型名、AI 总开关和文档开关。禁止依赖该接口获取密钥、数据库 URL 或内部配置。

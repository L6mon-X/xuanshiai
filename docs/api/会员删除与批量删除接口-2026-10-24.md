# 会员删除 / 批量删除接口（A12-会员删除）

> 变更日期：2026-10-24　关联清单：`后端接口缺失清单.md` 第 390 行「删除平台注册账号 / 批量删除」
> 口径：**软删除 `users.deleted_at`**，复用账号生命周期已有列，**不物理删、不新建迁移**（PROJECT_RULES §2.4）。
> 与后台账号 `DELETE /admin/accounts/{id}`（注销后台登录账号）**不同域**：本接口删除的是 C 端注册会员（`users`）。

## 1. 语义与数据来源

- **删除 = 打标**：`UPDATE users SET deleted_at=UTC_TIMESTAMP(), updated_at=UTC_TIMESTAMP() WHERE id=? AND deleted_at IS NULL`，不做 `DELETE FROM users`。
- **列表/详情默认排除**：`_member_query` 与会员详情在 `users.deleted_at` 列存在时自动追加 `u.deleted_at IS NULL`，软删行不再出现在 CRM 列表；列缺失（未跑 setup）时不拼该条件，避免 Unknown column。
- **幂等**：已再次删除（`deleted_at` 非空）不报错重复生效；批量按逐条归类成功/失败。
- **作用域收口（D-16）**：`scope_assignment.user_id = users.id`，越权或不存在的 ID 归入 `failed`，不改动数据。

## 2. 删除单个会员

**`DELETE /api/v1/admin/matchmaker/members/{member_id}`**

| 项 | 说明 |
|---|---|
| 权限 | `matchmaker.member.manage` |
| 状态码 | 成功 `200` |
| **敏感操作** | 必须携带 Header `Idempotency-Key`（8–128）且 Query `confirm=true`。**缺 `confirm` → `428`；缺/非法幂等键 → `422`。** |
| 幂等 | 同键同载荷只执行一次；重放直接返回上次结果 |

### 请求

- Path：`member_id`（int，`≥1`）
- Query：`confirm=true`（必填）、`reason`（选填，默认 `"后台删除"`，1–255 字，记入审计）
- Header：`Idempotency-Key: <8-128 chars>`（必填）

```http
DELETE /api/v1/admin/matchmaker/members/10086?confirm=true&reason=用户申请注销
Idempotency-Key: del-10086-20261024-0001
```

### 响应 `MemberDeleteResult`

| 字段 | 类型 | 说明 |
|---|---|---|
| `deleted` | array[int] | 本次成功软删的会员 ID |
| `failed` | array[object] | 失败明细 `{id, error}`；单删成功时为空数组 |

### 错误码

| 状态码 | 场景 |
|---|---|
| `404` | 会员不存在或不在数据作用域内 |
| `409` | 该会员已删除（`deleted_at` 非空） |
| `428` | 缺 `confirm=true` |
| `422` | 缺/非法 `Idempotency-Key` |
| `503` | `users.deleted_at` 列未就绪（未执行账号生命周期迁移） |

## 3. 批量删除会员

**`POST /api/v1/admin/matchmaker/members/batch-delete`**

| 项 | 说明 |
|---|---|
| 权限 | `matchmaker.member.manage` |
| Content-Type | `application/json` |
| 状态码 | 成功 `200` |
| **敏感操作** | Header `Idempotency-Key`（8–128）且 Query `confirm=true`；缺 `confirm` → `428`，缺/非法键 → `422` |
| 并发 | 命中行 `FOR UPDATE` 加锁后逐条处理 |

### 请求

Query：`confirm=true`（必填）
Header：`Idempotency-Key: <8-128 chars>`（必填）

Body `MemberBatchDeleteRequest`：

| 字段 | 类型 | 必填 | 约束 | 说明 |
|---|---|---|---|---|
| `member_ids` | array[int] | 是 | 1–200 项 | 目标会员 ID（自动去重） |
| `reason` | string | 是 | 1–255 字 | 批量删除理由，记入审计 |

```http
POST /api/v1/admin/matchmaker/members/batch-delete?confirm=true
Idempotency-Key: batch-del-20261024-0001
Content-Type: application/json

{ "member_ids": [10086, 10087, 10088], "reason": "重复注册清理" }
```

### 响应 `MemberDeleteResult`

```json
{
  "deleted": [10086, 10087],
  "failed": [
    { "id": 10088, "error": "该会员已删除" }
  ]
}
```

`failed[].error` 取值：`会员不存在或无权限` / `该会员已删除`。

### 错误码

| 状态码 | 场景 |
|---|---|
| `428` | 缺 `confirm=true` |
| `422` | 缺/非法 `Idempotency-Key`，或 `member_ids` 越界（空 / >200） |
| `503` | `users.deleted_at` 列未就绪 |

## 4. 审计

- 单删：`business_audit_log` 写 `action='member.delete'`、`resource_type='users'`、`resource_id=<member_id>`、`reason`。
- 批删：`action='member.batch_delete'`、`after_json=CAST({"member_ids":[...成功项]} AS JSON)`、`reason='批量删除N人: <reason>'`（截断 255）。
